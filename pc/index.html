🔌 Conexión

La IP aparece en la pantalla al mandar W (.--) en morse. Con el WiFi propio de la placa es 192.168.4.1. La clave es SHARED_SECRET de config.py.

👀 Vista previa

✏️ Texto

Si no entra en pantalla, se desliza como cartel de LED.

🖼️ Imagen o GIF

Los GIF animados se reproducen en loop (necesita Chrome o Edge).

📡 Comandos

Son los mismos comandos del morse. Ojo: apagar el WiFi corta la conexión con esta página.

🔤 Letras

Una letra sola en morse corre su código Python. Verde = tiene código · 🔒 = fija (W y B) · 🔐 = bloqueada para no editarla sin querer · gris = sin código, se escribe como texto.

Qué se puede usar en el código 
mostrar("Hola", "mundo")   # texto en pantalla (hasta 3 renglones)
tono(440, 300)             # nota en Hz durante 300 ms
esperar(1000)              # espera 1 segundo (SW2 corta el código)
led(True) / led(False)     # LED de la plaquita
imagen()                   # muestra la imagen X 3 segundos
deslizar("Hola!")          # cartel que cruza la pantalla
ayuda()                    # lista de letras con su título
mostrar_grande("7")        # texto gigante y centrado
esperar_toques(30000)      # espera que toques: "...", "-", o "" si no tocás
azar(1, 6)                 # número al azar (hardware + tus toques)
llave()                    # True mientras tocás la llave (para juegos)
sonar(440) / callar()      # sonido que no frena el código
escritura_libre()          # entra a escritura libre
oled, Pin, time            # para cosas más avanzadas

# Ejemplo, la L: prende el LED 10 segundos
led(True)
esperar(10000)
led(False)

Mapa de pines ESP32

La placa mirada con el USB arriba. Contamos los pines desde el USB, del 1 al 19: I = columna izquierda, D = columna derecha. Así decimos, por ejemplo, I7 (botón) o D19 (3.3V).

Los pines marcados como "solo entrada" (D14 a D17) sirven para leer (micrófono, sensores) pero no para prender cosas. Los del ADC2 (D5, D7 a D11) no pueden leer voltajes con el WiFi prendido; como pines comunes andan bien.
